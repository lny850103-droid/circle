# 무이판사판 웹사이트 설정 방법 (Firebase판)

로그인 없이 누구나 여는 웹사이트를 만드는 순서예요. 처음 한 번만 하면 되고, 40분 정도 걸려요.

| 누가 | 무엇을 | 어떻게 |
|---|---|---|
| 방문자 누구나 | 소개, 일정, 목표 보기 / 가입 신청서 내기 | 로그인 없이 바로 |
| 관리자 | 공지·소개·일정·목표 수정, 신청서 확인, 다른 관리자 승인 | 이메일·비밀번호로 **관리자 가입 → 승인** 후 로그인 |

비밀번호는 Firebase(구글 서비스)가 안전하게 보관해요. 누가 무엇을 읽고 쓸 수 있는지는 `firestore.rules` 파일이 서버에서 막아요.
요금은 무료(Spark 요금제)로 충분해요.

---

## 1단계. Firebase 프로젝트 만들기

1. [Firebase 콘솔](https://console.firebase.google.com)에 구글 계정으로 들어가요.
2. **프로젝트 추가** → 이름 `muipansapan` → Google 애널리틱스는 꺼도 돼요 → **프로젝트 만들기**.
3. 프로젝트 첫 화면에서 **웹 앱 추가(`</>` 아이콘)**를 눌러요. 앱 이름은 `homepage`로 하고 **앱 등록**을 눌러요. ("Firebase 호스팅 설정"은 체크하지 않아도 돼요.)
4. 화면에 나오는 `firebaseConfig` 중에서 아래 4개 값을 메모장에 복사해 둬요.
   ```
   apiKey: "AIza....",
   authDomain: "muipansapan-xxxx.firebaseapp.com",
   projectId: "muipansapan-xxxx",
   appId: "1:1234:web:abcd..."
   ```
   이 값들은 공개돼도 괜찮은 값이에요. 실제 보안은 3단계의 규칙이 맡아요.

## 2단계. 이메일 로그인 켜기

1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**.
2. **로그인 방법** 탭에서 **이메일/비밀번호**를 눌러 **사용 설정** → 저장.

## 3단계. 데이터베이스와 보안 규칙

1. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**.
2. 위치는 **asia-northeast3 (서울)** 을 고르고, **프로덕션 모드**로 시작해요.
3. 만들어지면 위쪽 **규칙** 탭을 열어요.
4. 들어 있는 내용을 모두 지우고, 이 폴더의 **`firestore.rules`** 파일 내용을 통째로 붙여 넣은 뒤 **게시**를 눌러요.
   - 메모장으로 `firestore.rules`를 열어 `Ctrl+A` → `Ctrl+C` 하면 돼요.

## 4단계. 사이트 파일에 설정값 넣기

1. `웹사이트` 폴더의 `index.html`을 **메모장**으로 열어요.
2. `Ctrl+F`로 `FIREBASE_CONFIG`를 찾으면 이 줄이 있어요.
   ```
   var FIREBASE_CONFIG = { apiKey: "", authDomain: "", projectId: "", appId: "" };
   ```
3. 1단계에서 복사한 값을 따옴표 사이에 넣고 저장해요.
   ```
   var FIREBASE_CONFIG = { apiKey: "AIza....", authDomain: "muipansapan-xxxx.firebaseapp.com", projectId: "muipansapan-xxxx", appId: "1:1234:web:abcd..." };
   ```

## 5단계. 웹사이트 올리기 (Netlify, 무료)

1. [Netlify](https://app.netlify.com/signup)에 가입해요(구글 계정 가능).
2. **Sites → Add new site → Deploy manually**를 누르고, `웹사이트` **폴더 전체**를 끌어다 놓아요.
   (`index.html`, `logo.png`, `bg.jpg` 세 파일이에요. `웹사이트 설정` 폴더는 올리지 마세요.)
3. **Site configuration → Change site name**에서 `muipansapan` 등으로 바꾸면 주소가 `https://muipansapan.netlify.app`이 돼요.
4. Firebase 콘솔 **Authentication → 설정 → 승인된 도메인**에 이 주소(`muipansapan.netlify.app`)를 추가해요.

## 6단계. 첫 번째 관리자 등록 (한 번만)

처음에는 승인해 줄 관리자가 없으니, 대표 한 명만 콘솔에서 직접 등록해요.

1. 내 사이트 주소에 들어가 오른쪽 위 **관리자 로그인 → 관리자 가입**으로 이름, 이메일, 비밀번호를 넣어요. "승인 대기 중"이 뜨면 정상이에요.
2. Firebase 콘솔 **Authentication → 사용자** 탭에서 방금 가입한 이메일의 **사용자 UID**를 복사해요.
3. **Firestore Database → 데이터** 탭 → **컬렉션 시작** → 컬렉션 ID에 `admins` 입력 → 다음.
4. **문서 ID**에 복사한 UID를 붙여 넣고, 필드 `name`(문자열)에 이름을 넣은 뒤 저장해요.
5. 사이트를 새로고침하면 **관리자 모드**가 켜져요.

그 다음부터는 콘솔에 들어갈 필요 없어요. 새 운영진이 사이트에서 **관리자 가입**을 하면, 관리자 모드의 **"관리자 가입 요청"** 목록에서 **승인** 또는 **거절**을 누르면 돼요.

## 운영하면서

- **공지·소개·일정·목표 바꾸기:** 관리자로 로그인 → 관리자 모드에서 바로 고치면 모든 방문자에게 즉시 보여요. 처음에는 일정과 목표가 비어 있으니 **+ 계획 추가**, **+ 목표 추가**로 올려 주세요.
- **가입 신청서 확인:** 관리자 모드의 **"가입 신청서 관리"**에서 보고, 상태를 검토 중·승인·보류로 바꿔요. 신청서는 관리자만 볼 수 있어요.
- **관리자 빼기:** Firestore **데이터 → admins**에서 그 사람의 문서를 삭제하면 돼요.
- **비밀번호를 잊은 관리자:** Authentication → 사용자에서 그 계정을 삭제하고, 사이트에서 다시 가입한 뒤 승인해 주세요.
- **디자인이나 사진을 바꿨을 때:** Netlify **Deploys** 탭에 `웹사이트` 폴더를 다시 끌어다 놓아요.
- **신청서 항목:** 이름, 학교, 생년월일, 학적 상태(재학·휴학·취업·취준생), 학과·학년, 출신(북한·남한·제3국출신), 연락처, 지원 동기, 개인정보 동의예요. 출신처럼 민감한 정보가 있으니 관리자 승인은 꼭 믿을 수 있는 운영진에게만 해 주세요.

## 참고

- 설정값을 넣기 전에는 사이트가 기본 소개와 예시 일정만 보여 주고, 신청서 자리에 "준비 중" 안내가 떠요.
- 예전에 만든 구글 시트·엑셀 방식 사이트는 `이전버전_구글시트판_index.html`로 보관해 두었어요. Firebase판에서는 일정을 엑셀 대신 관리자 모드에서 바로 고쳐요.
- 클로드 링크 버전(claude.ai)은 그대로 따로 동작해요. 그쪽 관리자는 클로드 공유 메뉴의 편집자예요.
