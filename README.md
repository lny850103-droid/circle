# 무이판사판 홈페이지

동국대학교 무이판사판(지혜와 자비, 평화와 통일을 향한 청년 연합 공동체) 동아리 홈페이지예요.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `웹사이트/` | 누구나 여는 공개 웹사이트 (Firebase판). Netlify 등에 이 폴더를 그대로 올려요. |
| `웹사이트 설정/` | Firebase 설정 안내서(`설정 방법.md`), 보안 규칙(`firestore.rules`), 일정·목표 엑셀/CSV 템플릿, 이전 구글 시트판 백업 |
| `홈페이지/` | claude.ai 링크(Claude Artifact)로 운영하는 버전 |

## 시작하기

`웹사이트 설정/설정 방법.md`의 1~6단계를 따라 Firebase 프로젝트를 만들고, `웹사이트/index.html`의 `FIREBASE_CONFIG`에 설정값을 넣은 뒤 배포하세요.

## 주요 기능

- 동아리 소개, 활동 계획, 목표 진행률, 발자취 지도 애니메이션, 인스타그램 QR
- 로그인 없이 가입 신청서 제출 (신청서는 관리자만 열람)
- 관리자: 이메일 가입 → 기존 관리자 승인 → 로그인 후 공지·일정·목표 수정과 신청서 관리
